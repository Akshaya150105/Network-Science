# Changepoint Detection in Preferential Attachment Networks Formed by LLM Agents

Network Science project (20XD92/20XD98), PSG College of Technology.

- Statistics side (Valincia): `pa_sim.py`, `mle.py`, `changepoint.py`, `analysis_stats.py`, experiments 01-03.
- LLM side (Akshaya): `prompts.py`, `llm_growth.py`, `analysis_llm.py`, experiments 04-06.

See `docs/` for the project documentation. The shared contract (seed graph `[2, 2]`, log format, results CSV schema) is in the plan files.

## Setup

```
pip install -r requirements.txt
python -m pytest tests
```

API keys go in environment variables only, never in code.

## Layout

```
src/          library code
tests/        unit tests
experiments/  runnable experiment scripts
logs/         LLM run logs (never edited by hand, never overwritten)
results/      CSV outputs and critical_values.json
figures/      plots
report/       report sections
docs/         project documentation
```

## Merge-phase files (statistics side)

```
src/analysis_stats.py                       M2 tables + shared per-run analysis; run: python -m src.analysis_stats
experiments/06_temperature_shift_analyze.py M1: needs logs/temp_n500_s*; --prefix/--logs-dir to test on fixtures
experiments/07_stats_figures.py             M3: figures/*.png from results/
experiments/08_rolling_delta.py             rolling-window delta_hat diagnostic (classical demo; or --prefix for real/fixture runs)
tests/make_fixture.py                       fake runs in the log contract format (never written into logs/ by default)
report/{method_statistics,controls,discussion,limitations_statistics,future_work,references}.md   M4
report/tables_statistics.md                 generated by src.analysis_stats, do not edit by hand
```

Stub and fixture runs are labelled `source = stub` and are excluded from the final tables.
